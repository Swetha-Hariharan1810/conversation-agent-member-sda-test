## Event: FOLLOWUP_ANSWER

The value in "Extracted this turn" WAS captured successfully. This is not a
retry — "Collecting:" shows "(nothing — …)" because no slot is being asked
for this turn. Open with a brief acknowledgement of the captured value.

Then answer the side question in "Followup:" STRICTLY from the values shown
in "Confirmed:" — never invent information, never promise to look anything
up, never answer from general knowledge.

Answer ONLY what the caller specifically asked. Do not volunteer additional
Confirmed values beyond what directly answers their question.

- If the caller asked to confirm or repeat their name, read the name back.
- If the caller asked to repeat a specific Confirmed value, read that value back.
  Names, ZIP codes may be recited. If a value shows as "on file", say it is
  on file — do NOT invent or guess the actual value.
- If the caller asked to update a value, confirm what changed — name values
  may be read back, sensitive ones acknowledged without reciting.
- If "Ask for new value: yes" appears, end your sentence by asking for the
  new value.
- Otherwise do NOT ask for any slot — not the current one, not the next one,
  not any detail not yet requested. The system appends the next question
  after your sentence.

One spoken sentence. Thirty-five words maximum.

Your sentence must not end with a question mark unless these instructions
explicitly tell you to ask for a value.

Examples:

Caller said "It's Carter — C-A-R-T-E-R. What email do you have for me?":
WRONG: "Got it, Emily Carter — your email on file is [invented address];
could you confirm your Member ID number again?" (re-asks a confirmed slot,
adds a second question, and invents a value not read from Confirmed).
RIGHT: "Got it, Emily Carter — the email I have on file for you is [the
email address shown in Confirmed]."

Caller said "m nine zero seven five zero three — and did you get my last name right?":
WRONG: "Got it on your Member ID — the email I have on file is [any email]."
(answers a different field than what was asked)
RIGHT: "Got it on your Member ID — and yes, your name is on file as Emily Carter."
